# Secret Definition

Именованные секреты для подстановки в конфигурацию gateway. `kind` — `gateway/secret/v1`.

## Поля

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `kind` | string | да | `gateway/secret/v1` |
| `weight` | int / string | нет | приоритет merge; default `0` |
| `name` | string | да | имя набора секретов |
| `values` | map[string]string | да | непустой словарь ключ → значение |

Несколько документов одного `name` объединяются по ключам от меньшего веса к большему. Значение из большего веса заменяет предыдущее значение того же ключа; остальные ключи сохраняются. При равных весах порядок не гарантируется. Вес — целое число; исходные строки `max` и `min` также поддерживаются и сортируются выше / ниже любого числового веса. См. [общие правила merge](README.md#загрузка-и-merge).

## Пример

```yaml
kind: gateway/secret/v1
name: authz
weight: 100
values:
  api_key: '$(AUTHZ_API_KEY)'
```

Ссылка из маршрута:

```yaml
interceptors:
  - id: authz
    parameters:
      apiKey: secret:authz:api_key
```

Проверку значения выполняет внешний интерцептор. Gateway подставляет секрет в его параметры. Секреты также могут использоваться в локальном Basic Auth; CSRF остаётся внешним интерцептором.

## Подстановки

`secret:<name>:<key>` заменяется значением ключа из итогового набора секретов. Ссылка должна занимать всю строку. Строки без префикса `secret:` остаются literal, за исключением env-подстановок.

Порядок: merge исходных документов → env-подстановки → secret-подстановки → валидация и defaults → компиляция regexp. Поддерживаются `$(VAR)` и `$(VAR:-default)`: default используется для отсутствующей или пустой переменной. Отсутствующая переменная без default, некорректная ссылка или отсутствующий secret/key — ошибка запуска.

Secret-ссылки разрешены в `interceptor.address`, `interceptors[].parameters`, `addHeaders.*.value` и `basicAuth.users`. Secret может содержать env-подстановку, но не ссылку на другой secret; рекурсивное раскрытие не поддерживается. Значения секретов не выводятся в логи и диагностику; ошибка указывает имя/key и место ссылки.

Пример секрета для локального Basic Auth:

```yaml
kind: gateway/secret/v1
name: basic_auth
values:
  cred: 'user1:{SHA}EIRU7AdrXt4H/...'
```

Строка хеша иллюстрирует формат; для рабочего запуска требуется реальная htpasswd-запись.
